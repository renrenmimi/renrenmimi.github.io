Inside the build

Drop a Claude Code transcript on the page and step through the run: the messages array as it grew, the step that blew up the context, and what it had read before it wrote. Compare two runs, or index every session on your machine at once — all parsed incrementally in the browser, nothing uploaded. A rule set runs the same checks from the command line and exits non-zero, so it fits in CI.

Real-Time AI Communication Coach+

A real-time coach that scores how you're coming across as you speak — live transcription, LLM tone analysis, and audio signals combined into one score. Three views over a public repository: Replay walks the default branch commit by commit, Compare puts any two points side by side, and Insights tracks how size and structure moved. File trees are rebuilt from checkpoints and diffs, the GitHub token stays on the server, and a synthetic demo spends no API quota.

TaxLot

Investment Tracking & Tax Estimates+

Track investment lots, explain realized gains, and check wash sales across a household's accounts. Import transactions, reconcile them against brokerage statements, and try a sale before making it. A standalone TypeScript engine handles the calculations; the bilingual Expo app keeps your data in your own browser, with safeguards against competing writes from other tabs.

iCanDoIt

Native macOS Day Planner+

Attach a reward to each task; clear them all and the app throws confetti for a Perfect Day. It builds as a plain Swift package, SwiftUI and SwiftData only. Two hidden flags: --snapshot renders every screen to PNG offscreen, --selftest checks what screenshots cannot, like drag-and-drop placement and schema backfill.

02 / LEARN BY DOING

Learning Tools✳

Free lessons and practice for beginners and intermediate learners.
Each tool helps you learn a topic by trying it.

ALL LIVE IN PRODUCTION · FREE TO USE

BoxArrow

Learn system design through interactive diagrams and experiments: how clients, servers, databases and rate limits fit together. English and Chinese.

System design · EN / 中文↗

DataData

Learn data structures through memory diagrams and animations you can step or predict. Compare Java, Python and JS, then practice with worked problems.

14 chapters↗

AlgoAlgo

Learn how algorithms decide with step-through decision trees, DP tables and binary search. Compare sorting strategies by comparisons, moves and space.

13 chapters↗ CLIENT GET200 API

APIer

Learn HTTP, REST and GraphQL, from your first request to auth, caching and versioning. Practice with a mock API and request inspector in your browser.

12 chapters↗ const score =42 → inferrednumber

TSer

Learn TypeScript from first principles. Edit code, get errors and inferred types from the real compiler in a Web Worker, and practice what each concept means.

12 chapters↗

RedisVisual

Learn Redis through data structures, caching, concurrency guards and read models, then test your understanding in a hands-on lab and fault simulator.

8 stops↗

DrillLab

Build independence with 80 lessons, 105 recall questions, 148 exercises, 25 coding problems and 7 timed builds, organized into six guided learning plans.

80 lessons↗ UplanAtool?Tresult LOOP ↻

AgentLab

Learn how tool-using agents work: watch messages and tool calls, build an agent by stop three, then explore context, cost, failure handling and trust.

14 stops↗ ×broken → ✓fixed

Bug Museum

Learn to debug through six real cases: reproduce each failure, investigate its cause, compare fixes and run the regression test that prevents it from returning.
